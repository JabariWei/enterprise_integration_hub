# 2. Tenant 租户表

## tenant

企业主体。


```sql
CREATE TABLE tenant
(
    id UUID PRIMARY KEY,

    name VARCHAR(128) NOT NULL,

    code VARCHAR(64) UNIQUE,

    status VARCHAR(32)
        DEFAULT 'active',

    settings JSONB DEFAULT '{}',

    created_at TIMESTAMP DEFAULT now(),

    updated_at TIMESTAMP DEFAULT now()
);
```

---

字段说明：

|字段|用途|
|-|-|
|id|内部租户ID|
|code|企业编码|
|settings|企业配置|

# 4. Connector 实例表


## connector_instance


一个企业可以绑定多个平台。


例如：

A企业：

```text
企业微信生产环境

飞书生产环境
```


表：

```sql
CREATE TABLE connector_instance
(
    id UUID PRIMARY KEY,


    tenant_id UUID NOT NULL,


    provider_id UUID NOT NULL,


    name VARCHAR(128),


    status VARCHAR(32),


    config JSONB DEFAULT '{}',


    created_at TIMESTAMP DEFAULT now(),


    FOREIGN KEY(tenant_id)
    REFERENCES tenant(id)

);
```

---

关系：

```text
Tenant

 1

 |

 N

Connector
```

```sql
(
connector_id,
capability_id
)

);
```

---
