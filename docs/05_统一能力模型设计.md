# 第五部分：统一 API Schema 与 Connector SDK 架构设计

这一部分是整个项目从“调研”进入“可开发设计”的关键。

目标：

设计一个类似：

- Stripe Payment Adapter
- Airbyte Connector
- Apache Camel Component
- Zapier App Connector

的企业能力连接框架。

最终效果：

任何系统：

- CRM
- ERP
- OA
- AI Agent
- RPA
- 企业应用

只需要调用统一 API。

---

# 1. 总体架构设计

## 1.1 系统定位

项目名称：

> Enterprise Integration Hub（企业集成中台）


架构：

```
                 外部业务系统

        CRM / ERP / AI Agent / OA
                    |
                    |
              Unified API Layer
                    |
        --------------------------------
        |
        Core Service
        |
        |
   Connector Runtime
        |
 ---------------------------------
 |              |                |
企业微信        飞书             钉钉

Adapter       Adapter          Adapter

 |              |                |

WeCom API   Feishu API      DingTalk API
```

# 2. 核心设计思想

## 2.1 三层模型


不要：

```
业务系统
 |
企微API
```

而是：


```
Business Capability

        ↓

Canonical Model

        ↓

Provider Adapter
```

---

业务：

```
发送通知
```


统一：

```

```


底层：

```
WeComMessageAdapter

FeishuMessageAdapter

DingTalkMessageAdapter
```

# 4. Database 数据模型设计


## 4.1 Tenant


多企业支持。


表：

```
tenant
```


字段：

|字段|说明|
|-|-|
|id|主键|
|name|企业名称|
|status|状态|
|created_at|创建时间|


---

## 4.2 Provider


记录平台。


```
provider
```


数据：

|id|name|
|-|-|
|1|wecom|
|2|feishu|
|3|dingtalk|


---

## 4.3 Connector Instance


一个企业绑定一个平台。


例如：

A公司：

绑定：

- 企业微信
- 飞书


表：

```
connector_instance
```


结构：

```json
{
"id":"",

"tenant_id":"",

"provider":"feishu",

"name":"飞书生产环境",

"status":"active"

}
```

# 6. Unified API 设计


## 6.1 用户 API


获取用户：

```
GET

/api/v1/users
```


返回：

```json
[
{
"id":"001",

"name":"张三"

}
]
```

---

查询：

```
GET

/api/v1/users/{id}
```

---

同步：

```
POST

/api/v1/users/sync
```


---

# 6.2 部门 API


```
GET /departments

GET /departments/tree
```


---

# 6.3 消息 API


发送：

```
POST

/api/v1/messages/send
```


请求：

```json
{
"receiver":

{
"type":"user",

"id":"001"

},


"message":

{

"type":"text",

"text":"hello"

}

}
```

---

返回：

```json
{
"id":"message001",

"status":"sent"

}
```

---

# 6.4 文件 API


上传：

```
POST

/api/v1/files/upload
```


下载：

```
GET

/api/v1/files/{id}
```
